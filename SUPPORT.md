# Support Guidelines for C.O.P.P.E.R.

Welcome to the C.O.P.P.E.R. support page! Here is how to get help, find answers, and report issues.

---

## How to Get Help

### 1. Check Documentation & FAQs
Before opening an issue, check the comprehensive documentation in [`docs/`](docs/README.md):
- **Setup Issues:** Consult [`docs/setup/development.md`](docs/setup/development.md) and [`docs/setup/troubleshooting.md`](docs/setup/troubleshooting.md).
- **Architecture & Agents:** Consult [`docs/architecture/overview.md`](docs/architecture/overview.md).
- **Model Downloads & Manifest:** Consult [`docs/setup/models.md`](docs/setup/models.md).

### 2. GitHub Issues
If you encounter a bug or have a feature request:
- **Bug Report:** Use the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md) with reproduction steps.
- **Feature Request:** Use the [Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md).

---

## Security Vulnerabilities
If your issue involves a security vulnerability or bypass, please follow our [Security Policy](SECURITY.md) and do not open a public issue.
