7. Abstract (Character count: 1,845 / 1,920 arXiv max limit):
Equipping local-first autonomous agents with persistent episodic memory enables multi-session personalization, but introduces an insidious vulnerability: delayed memory poisoning. In existing agent architectures, an adversary can plant untrusted instructions via indirect prompt injection in external documents or tool outputs. Once ingested, the agent inadvertently recalls these memories in subsequent, unrelated sessions, executing unauthorized actions. Crucially, contemporary agent systems (e.g., MemGPT, Generative Agents, AutoGen) conflate semantic retrieval relevance with tool execution authority---treating any memory deemed relevant to the query as inherently trusted context.

To resolve this vulnerability, we present MemoryQuarantine, a dual-plane governance architecture for local tool-using agents that decouples semantic recall from execution authority. MemoryQuarantine introduces consequence-calibrated authorization: the permission of memory m to authorize action a is bounded by Authority(m, a) = gamma(m) * C(m) * (1 - R(a)), coupling immutable source provenance gamma(m), calibrated epistemic confidence C(m), and semantic action reversibility risk R(a) enforced deterministically at the tool boundary. We evaluate MemoryQuarantine on CopperMemoryBench (160 multi-session traces spanning direct injection, indirect poisoning, delayed steering, bridging subversion, and contradiction floods) and an end-to-end physical execution harness running local models on an NVIDIA GeForce RTX 5060 Laptop GPU. MemoryQuarantine achieves an Attack Success Rate (ASR) of 0.0% (down from 100.0% in flat vector RAG and 80.0% in Bayesian baselines, two-tailed Fisher's exact p = 2.21 x 10^-59) and a Threat Interception Rate of 100.0% (exact 95% Clopper-Pearson CI: [96.4%, 100.0%]), while preserving 100.0% benign task completion with zero false quarantines and under 0.01 ms evaluation latency.
