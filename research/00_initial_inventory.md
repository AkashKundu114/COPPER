## 4. Conflicting or Outdated Documentation & Claims

1. **Routing Accuracy Conflict:**
   - `research/paper.tex` (IEEE draft) claims: **97.77% accuracy** across 1,390 queries.
   - `backend/eval/benchmark_report.md` (Oct 17, 2026 audit) records: **56.87% accuracy** (Weighted F1: 57.1%) across 12,204 samples.
   - *Root Cause:* The 1,390 dataset perfectly aligns with handcrafted keyword regexes in `agent_router.py`. The scaled 12,204 benchmark generated prompts with arbitrary conversational affixes and introduced categories (`behavior`, `voice`) for which no router agent class exists in `AgentType` (resulting in 0.0% F1 for both).
2. **Guardian Safety Sensitivity Conflict:**
   - `research/paper.tex` claims: **99.83% threat-catch sensitivity** (1,737/1,740 intercepted).
   - On the 350-sample dataset, sensitivity is 100%.
   - On the 11,501 scaled dataset, sensitivity dropped to **93.3%** with **770 unblocked breaches (6.7% FNR)**.
3. **Data Firewall & Zero-Egress Claim vs Implementation:**
   - `paper.tex` characterizes the Zero-Trust Data Firewall as a subprocess network security boundary preventing outbound token exfiltration.
   - In reality, `backend/app/core/data_firewall.py` is an application-level string regex redactor (matching 17 patterns like `sk-`, `ghp_`, emails, credit cards). It does not hook Windows network sockets, WFP (Windows Filtering Platform), or iptables.
4. **Number of Agents:**
   - `paper.tex` claims "30 coordinated agent roles".
   - `AgentType` in `backend/app/core/constants.py` has strictly **12 core enum members**. The 30 roles include sub-agent configurations and planned roadmap personas (`test_agent_registry_counts.py`).

## 5. Initial Candidate Research Questions

Following critical assessment of the system's actual code, experimental data, and internal notes (`gap_analysis.md` and `memory_quarantine.md`), we identify four candidate directions:

- **Candidate RQ1 (Local Multi-Tier Routing Under Syntactic Perturbation):**
  *Question:* How does a CPU-only cascaded heuristic-plus-embedding router perform under adversarial prompt prefixes, stylistic noise, and unseen intent shifts compared to zero-shot SLM routers?
  *Viability:* Low-to-Medium. Current heuristic router degrades sharply (to 56.87%) when perturbed; elevating it would require training a lightweight neural intent embedder (e.g., SetFit or MobileBERT).

- **Candidate RQ2 (Continuous Dynamic Friction vs Static Binary Guardrails in Local Agent Execution):**
  *Question:* Does modulating safety intervention via a continuous action-reversibility and session-fatigue friction index ($\mathcal{F}_{\text{dynamic}}$) reduce operator confirmation fatigue while maintaining zero destructive breaches compared to static thresholding?
  *Viability:* High. Supported by real mathematical implementation in `guardian.py` and calibrated by `calibrate_friction.py`, but requires a human-in-the-loop or simulated operator workload protocol.

- **Candidate RQ3 (Trustworthy Persistent Memory & MemoryQuarantine for Local Agents — Recommended):**
  *Question:* Can a provenance-aware memory authorization layer (*MemoryQuarantine*) decouple semantic retrieval relevance from action authority to prevent delayed persistent prompt injection and memory poisoning from triggering consequential tool execution?
  *Viability:* **Highest**. Solves the primary methodological gap identified in `gap_analysis.md`. The mechanism bridges `memory_manager.py` (provenance, confidence, decay) with `guardian.py` (action reversibility, friction). It can be rigorously evaluated using reproducible synthetic and benchmarked poisoning attack traces without downloading multi-gigabyte LLM weights.

- **Candidate RQ4 (Subprocess Airgap & Egress Verification in Local AI Systems):**
  *Question:* How effectively can application-level regex redaction combined with local socket isolation prevent accidental secret exfiltration across multi-agent tool execution?
  *Viability:* Medium. Would require implementing real OS-level network instrumentation (packet sniffing/socket hooks) to turn descriptive claims into empirical measurements.
